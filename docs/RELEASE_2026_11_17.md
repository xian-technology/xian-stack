# Release handoff: 2026-11-17

## Scope and decisions

User authorized stable releases for every existing package/app release workflow,
correct downstream pins, and one stack image build. Publish dependencies before
consumers. Check GitHub validations on the exact tag commit. Stack images run
last; hand off their workflow URL without monitoring the image publication.
This is a current-code release, not a public-network launch or a live-node upgrade.

Use the workspace release skill and orchestrator. Prepare metadata commits
before applying tags because the orchestrator can otherwise tag a new version
commit immediately after pushing it, before that commit's checks have run.
Python/Rust/npm versions must agree. Retain intentional historical migration
pins; xian-intentkit stays outside this train as an exempt fork.
